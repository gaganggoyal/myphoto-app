# myphoto-app

A Rails 5.2 starter with user accounts: Devise for sign-up and login, styled
with Bootstrap, and PostgreSQL set up for production.

**Stack:** Ruby 2.7, Rails 5.2, Devise, Bootstrap, SQLite / PostgreSQL

## Run it

```bash
bundle install
bin/rails db:setup
bin/rails server
```
